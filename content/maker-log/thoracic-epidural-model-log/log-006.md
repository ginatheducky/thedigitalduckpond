So far, I've been printing everything in PLA. It's easy to print, but there's one problem: I want the model to be washable and reusable.

PLA doesn't handle heat particularly well and can start to soften or deform when exposed to hot water. Not exactly ideal for something that might need regular cleaning, especially if we're using gelatine.

So I've decided to switch to ABS, which has much better heat resistance and should make the model more suitable for cleaning with warmer water.

For this project, I'm using ABSx from [Nobufil](https://www.nobufil.com/).

ABS is a bit more challenging to print than PLA, but hopefully the improved heat resistance will be worth the extra effort.
